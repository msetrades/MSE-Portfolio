# The MSE Portfolio

Static portfolio and print-ready résumé site. Deploy as a standalone project to Vercel.

## Before launch

- Replace `msetrades@gmail.com` with a confirmed professional contact email.
- Replace résumé placeholders with a name and contact details the owner wants public.
- Confirm public project URLs and add only security research findings that have been cleared for disclosure.
- The site uses no private source code, credentials, or customer data.

## Deploy

Import this directory as a separate Vercel project or run `vercel --prod` from this directory. The résumé is available at `/cv` and can be saved as PDF from the browser print dialog.
